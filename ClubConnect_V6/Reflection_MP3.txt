URLSession and Codable in iOS play roles similar to Retrofit and Gson in Android because they retrieve remote data and convert JSON into typed model values. PHPickerViewController is comparable to Android Photo Picker because both let the user select media through a system interface without giving the app unrestricted photo-library access. CLLocationManager is similar to FusedLocationProviderClient because both provide device location updates after the appropriate authorization flow. In this project, asynchronous callbacks also require UI updates to be returned to the main thread before changing UIKit controls.
