UITableView and UITableViewDataSource are similar to RecyclerView because both display a reusable, scrollable collection whose rows are supplied from a data source. A custom UITableViewCell plays a role similar to a RecyclerView ViewHolder by connecting row views to one record. UserDefaults is comparable to SharedPreferences for small preference values, while Core Data is closer to Room or SQLite because it stores structured records persistently. Core Data also uses a managed object context and fetch requests, so the app works with stored objects instead of directly writing SQL statements.
